# FRONTLINE: ZERO

Browser-first tactical warfare sandbox inspired by large-scale command RTS games, built as an original project.

## Current playable prototype

- React + Vite + TypeScript shell
- Phaser tactical battlefield
- Premium military HUD and custom SVG branding
- Battlegroup with recon, tanks, infantry, artillery, SAM and helicopter icons
- Drag selection / click selection
- Right-click formation movement
- WASD camera movement and mouse-wheel zoom
- Two factions with basic autonomous enemy AI
- Unit-specific speed, range, health and damage
- Automatic combat, tracers and destruction effects
- Tactical zones, roads, forest blocks, urban area and capture-point visuals
- Responsive lobby and battle HUD
- GitHub Pages deployment workflow

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Controls

- **LMB** — select a unit or drag-select several units
- **RMB** — move selected units in formation
- **WASD** — pan camera
- **Mouse wheel** — zoom
